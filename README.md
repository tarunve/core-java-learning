# core-java-learning

Core Java learning repository covering core concepts, design patterns, reactive programming, JUnit/Mockito testing, and Java version enhancements from Java 7 through 17.

## Structure

- `java-basics-001-core-concepts/` - Core Java concepts
- `java-basics-002-design-patterns/` - Design patterns
- `java-basics-003-reactive/` - Reactive programming
- `java-basics-004-junit-mockito/` - JUnit and Mockito testing
- `java-basics-005-enhancements-07 through 17/` - Java version enhancements (Java 7-17)
